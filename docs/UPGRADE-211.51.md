# 2.0.211.51 迁移说明

日期：2026-10-02。状态：适配测试版；开发和补字工作保持暂停，此次只整理和上传已有成果。

这是覆盖式汉化补丁。游戏通过 Mono 加载 `Assembly-CSharp.dll`，通过数据加载器读取 `StreamingAssets/Base`，由 TextMeshPro 使用 `sharedassets0.assets` 内的字形和图集渲染文本。

## 程序文本

以原版 211.51 DLL 为底稿。方法结构指纹包含方法签名、指令及非字符串操作数、分支目标、局部变量、最大栈和异常处理；仅在比较时把 `ldstr` 操作数统一为占位值。匹配后只修改批准位置的字符串，不移植旧方法体。

7,089 处程序字符串包含 6,986 处相同方法结构匹配、97 处已变化方法的原文精确匹配、6 处已变化菜单方法的相邻命令匹配。后一种匹配要求文本立即写入显示字段，附近存在相同且唯一的英文命令。

资源/命令键、已知数据标识、比较或条件消费者、字典键等位置会被过滤。每次写入核对方法指纹、指令序号及原始英文。完成后比较全部 7,837 个类型、63,457 个方法，验证仅批准的字符串发生变化，方法结构、字段、程序集版本、引用及嵌入资源保持。

这些规则属于静态筛选；字符串本身也可能参与逻辑，方法结构一致不能证明全部行为兼容。未完成的运行测试仍然必需。

使用 .NET 9 运行 Mono.Cecil 0.11.6 处理工具，不会把游戏运行时改成 .NET 9，也不重新编译整套游戏。需要复核或重建 DLL 时，可以使用**匹配 manifest 原始哈希的本地 211.51 DLL**运行：

```powershell
dotnet build tools/cecil/QudMigration.csproj -c Release
dotnet tools/cecil/bin/Release/net9.0/QudMigration.dll patch <原版DLL路径> verification/approved-literals.json <输出DLL路径> <原版Managed目录>
```

上述命令是参数示例；始终指定独立输出位置。这里只提供 DLL 处理工具，尚未整理完整的一键重建数据和字体流水线。

## 数据文本与标识

新版数据结构及数值为底稿，优先按稳定 ID/Class/Name 等字段匹配。无稳定键时，部分同数量且无标识冲突的条目采用顺序匹配。显示字段使用格式白名单；占位符、描述中的数字、标记平衡不一致时跳过。结构变化或语义变化仍可能影响顺序匹配和译文，需要人工抽查。

211.51 任务加载器支持独立 `ID` 和 `Name`。迁移中文标题时补入原来的任务/步骤 ID，所有任务条件和引用保持英文。突变和职业利用已有 `DisplayName` 显示中文，保留原 `Name`。技能未找到等效显示字段，名称保持英文，迁移说明。

数据日志记录 15,330 处属性/文本变化。新增的任务 ID 用原名称补齐，验证时独立检查其身份等价性；变化计数不等同于句子数或汉化覆盖率。解析过程中临时保护游戏采用的控制字符实体，保存时恢复原写法。

## 字体

旧资产为 Unity 6000.0.41f1，新资产为 6000.0.77f1。只迁移 Regular SDF 的字形表、字图和相关配置，保留新版对象身份及引用：

| 对象 | 旧编号 | 新编号 |
|---|---:|---:|
| TMP 字体 | 2625 | 2616 |
| 字形图集 | 263 | 266 |
| 字体材质 | 35 | 37 |
| 外部 TMP 脚本引用 | 2788 | 2859 |

图集为 4096×4096 Alpha8、16 MB 内嵌数据，清除该图集旧 stream 地址；新版其他资源流引用保持。材质尺寸改为 4096/4096，GradientScale 改为 6，匹配 padding 5。保留新版 shader。

重新读取保存后的资产检查 Unity 版本和 4,379 个对象；仅 3 个对象变化，其余 4,376 个对象的原始字节哈希一致。原版 333 个字符全部保留；迁移字体含 6,989 个汉字。扫描当前语料 3,270 个独特汉字后发现 10 个缺字，尚未补齐。补字工作原计划在独立临时 Unity 项目中使用 FontEngine 生成 SDFAA 字形，现已暂停。

## 运行证据与局限

游戏副本使用独立 Save/Local/Synced 路径启动。已观察中文主菜单和游戏模式选择界面。发布前再次比较测试副本与发布 payload 的全部 32 个文件，哈希一致。

尚未完成角色创建、进入世界、任务推进或保存读档测试；没有完成全译文人工校对，也未覆盖全部新文本。静态检查通过、文件哈希一致和界面截图都不能替代这些流程验证。
