# 卡德洞窟（Caves of Qud）2.0.211.51 汉化适配测试版

**实验性预发布，尚未完成完整游戏流程验证。** 本分支将 lofucc 的 210.20 汉化迁移到 Windows x64 Mono 版 **2.0.211.51 / Unity 6000.0.77f1**。仍有英文文本和 10 个字库缺字；不宣称完整汉化或译文经过全面人工校对。

[下载预发布安装包](https://github.com/EriaWalker/caves-of-qud-chinese/releases/tag/v2.0.211.51-experimental.1) · [查看验证说明](docs/UPGRADE-211.51.md)

## 安装与回滚

1. 确认游戏为 **2.0.211.51**，关闭游戏。
2. 备份 `manifest.json` 所列的 32 个游戏原文件，并自行备份存档。清单提供验证时原文件的 SHA-256 和补丁文件的 SHA-256。
3. 下载 Release 附件 `qud-chinese-2.0.211.51-experimental.1.zip`，把包内 `CoQ_Data` 合并到游戏根目录的同名文件夹，覆盖清单中的文件。
4. 如需回滚，关闭游戏后恢复自己备份的这 32 个原文件。不要使用旧版 210.20 DLL 或资产文件回滚 211.51。

仓库源码下载包与 Release 安装包的目录不同：本分支的 `Managed`、`StreamingAssets` 和 `sharedassets0.assets` 对应游戏的 `CoQ_Data` 内部。推荐使用上面的 Release 安装包。

补丁仅含 32 个待替换文件；没有附带游戏可执行文件、原文件备份、用户存档或账号日志。旧包中未迁移的 7 个数据文件已从本分支移除，安装时保留游戏自带文件。

## 文件与证据

- `manifest.json`：32 个补丁文件及原文件的哈希。
- `verification/`：静态检查、字体检查、运行验证范围和逐条迁移/跳过记录。
- `tools/cecil/`：程序集字符串迁移工具源码。它处理指定的 DLL，不在游戏内加载。
- `docs/UPGRADE-211.51.md`：迁移原理、边界和复核方法。

原始汉化来自 [lofucc/caves-of-qud-chinese](https://github.com/lofucc/caves-of-qud-chinese)，固定提交 `70bcb618ead20412ba9ed4bfbf11ead7462bdc32`。上游 README 说明大部分文本采用 AI 翻译和简单人工校对。本适配主要处理版本兼容性，沿用上游翻译，不代表重新完成了全面校译。原项目历史保留在 `Changelog.md`；`main` 分支保留 210.20 内容。
